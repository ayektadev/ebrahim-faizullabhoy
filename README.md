# ebrahim-faizullabhoy

Personal website, published with GitHub Pages at
https://ayektadev.github.io/ebrahim-faizullabhoy/

## Writing a blog post

1. Create a file in `_posts/` named `YYYY-MM-DD-short-title.md`.
2. Start it with:

   ```
   ---
   title: "Post title"
   description: "One-line summary shown on the home page."
   ---
   ```

3. Write the post below in Markdown, then commit and push.

See `_drafts/example-post.md` for a template. Files in `_drafts/` are never published.

## Updating the CV or photo

Replace `assets/docs/Ebrahim_Faizullabhoy_CV.pdf` or `assets/img/headshot.jpg`
with a file of the same name and push.
