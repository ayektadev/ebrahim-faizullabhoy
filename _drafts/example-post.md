Drafts in this folder are NOT published. To publish a post:

1. Copy this file into the `_posts` folder.
2. Rename it with the date first: `2026-11-20-short-title.md`
3. Replace this text with your post, written in plain Markdown.
4. Commit and push. It appears under Writing within a minute or two.

## Formatting cheat sheet

A blank line starts a new paragraph. Use `## ` for a section heading,
**double asterisks** for bold, [text](https://example.com) for links,
and `> ` at the start of a line for a quote.
